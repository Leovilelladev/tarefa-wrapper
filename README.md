# Tarefa Wrapper

Exercício EBAC sobre conversão de um tipo primitivo para o respectivo tipo wrapper em Java.

## Como executar

Compile e execute a classe com:

```bash
javac src/main/java/ConversaoWrapper.java
java -cp src/main/java ConversaoWrapper
```

Informe um número no console para visualizar a conversão de `int` para `Integer`.
